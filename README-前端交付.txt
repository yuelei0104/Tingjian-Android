听见 Android · 前端完整交付版

使用方法：在 Android Studio 打开解压后的 tingjian-android 文件夹，等待 Gradle 同步，选择模拟器或已连接的真机，点击运行。

代码模块（app/src/main/java/com/tingjian/app）：
- MainActivity.kt：应用入口、全局状态与页面导航。
- AppModels.kt：会话数据模型、本地持久化与演示数据。
- CommonUi.kt：颜色、通用按钮、气泡、卡片和底部导航。
- WelcomeHomeScreens.kt：欢迎页与首页。
- LiveScreen.kt：实时字幕、语音识别、文字播报与表达辅助。
- HistoryScreens.kt：会话列表、搜索、详情与摘要。
- AccountScreens.kt：登录、用量、我的和设置。

已完成的前端模块：
1. 欢迎页、首页、课堂/会议/就医/日常场景、离线提示、最近会话和用量页。
2. 面对面字幕：首次麦克风说明、权限设置入口、点击一次后持续监听与自动分句重启、会话计时、暂停/继续、连接/重连、中文/英文/中英混合、左右聊天气泡、自动滚动开关、关键词高亮与震动冷却、文字输入、快捷回复、表达助手、撤销建议、发送并播报、停止、重试和重播。
3. 会话记录：本机保存、搜索、时间/场景筛选、分页加载、详情时间轴、关键词高亮、摘要生成/重试/删除状态、重命名、纯文字分享、单条删除和清空全部，最多保留 100 段。
4. 我的：大字字幕、关键词高亮/震动分别开关、自动摘要、识别语言、播报语言/音色/语速、术语的别名/语言/类别/优先级/启用管理、快捷短语增删改排序、用量、隐私、识别服务和异常状态预览。
5. 演示账户：获取验证码冷却、协议/隐私说明、登录、退出确认和验证注销。演示手机号为 13800000000，验证码为 123456，不会发送真实短信。
